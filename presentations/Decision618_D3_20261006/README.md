The deck reports the NextItNet experiment and per-user next-item holdout documented in the October 6 delivery. The October 7 course rebuild elsewhere in this repository evaluates star-rating predictions using softImpute, metadata and timestamp features. Their prediction targets, splits and metrics differ. This deck retains its October 6 content and does not present the October 7 results.

Download the PDF for display, or download the PowerPoint and install the fonts in `fonts/` before editing. Open the HTML file locally in a browser. Arrow keys or Space advance slides, F enters fullscreen, N shows notes, T toggles the timer, and E enables text editing. Ctrl/Cmd+S exports an edited HTML copy.

All nine presentation and supporting files match their existing local originals byte for byte. Uploading them to GitHub does not submit them to Canvas.
